### 使用

图标按目录分类存放：

```text
svg/
├── app/      应用图标
├── brand/    品牌图标
├── network/  网络 / 国旗图标
└── tech/     技术栈图标
```

#### jsDelivr（推荐，带 CDN 加速）

```text
https://cdn.jsdelivr.net/gh/<用户名>/<仓库名>[@版本或分支]/<文件路径>
```

```bash
# 不写版本时默认取最新提交
https://cdn.jsdelivr.net/gh/weiShaoY/imgCloud/svg/tech/javascript.svg

# 建议锁定分支或版本，避免后续改动 / 缓存影响
https://cdn.jsdelivr.net/gh/weiShaoY/imgCloud@main/svg/tech/javascript.svg

# 图片
https://cdn.jsdelivr.net/gh/weiShaoY/imgCloud/img/programmer.jpg
```

浏览目录：<https://cdn.jsdelivr.net/gh/weiShaoY/imgCloud@main/svg/>

#### GitHub Raw（仅支持单个文件）

```text
https://raw.githubusercontent.com/<用户名>/<仓库名>/<分支>/<文件路径>
```

```bash
https://raw.githubusercontent.com/weiShaoY/imgCloud/main/svg/tech/javascript.svg
```

> 注意：第三段必须是**分支名**（本仓库为 `main`），且 Raw 只能访问**单个文件**，不能访问目录。
> 查看目录请用 GitHub 网页：<https://github.com/weiShaoY/imgCloud/tree/main/svg>
